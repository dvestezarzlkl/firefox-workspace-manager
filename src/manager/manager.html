Jazyk rozhraní

Výběr se ukládá lokálně. Přepnutí znovu načte pouze rozhraní správce a popupu, nikoli Firefox.

Záloha aplikace

Kompletní disaster-recovery záloha nastavení, workspace a přenositelných metadat.

Runtime Firefox ID, aktivní mapování oken, countdowny a snapshot lock se nezálohují. Restore nechá otevřená Firefox okna beze změny. Pokud celý workspace přesně odpovídá živým oknům, automaticky obnoví jejich vazby a aktivní stav. Při rozdílu panelů nebo nejednoznačné shodě zůstanou workspaces neaktivní; Recover session výslovně upozorní, že by vytvořil další okna.

Synchronizace

Synchronizují se AUTO nastavení, hostname politiky a URL výjimky. Runtime taby, countdowny, statistiky a snapshoty oken zůstávají lokální.

AUTO

Hodnoty se ukládají už teď; automatické vyhodnocování AUTO zapojíme v dalším kroku.

URL výjimky

Nejkonkrétnější pravidlo má přednost před hostname. Pro stránku, která musí držet EventSource/WebSocket, použij přesnou URL výjimku KEEP.

Politiky podle hostname

Pravidlo platí pro celý hostname, například sub.domena.cz.

Načítám…

Základní princip

Workspace Manager drží pracovní prostředí jako sadu oken, skupin a panelů. Panely mohou zůstat načtené, automaticky přejít do DEEP nebo být chráněné před discardem.

Stavy panelů

KEEP ALWAYS
Hostname je chráněný a zůstává načtený.
AUTO
Panel se po nastavené době neaktivity automaticky discardne. Odpočet je vidět přímo u panelu.
DEEP ALWAYS
Neaktivní panel tohoto hostname má být vždy discarded. 30s watchdog tento stav průběžně kontroluje.
EXCEPT
Přesná celá URL je výjimka KEEP, i když má její hostname například DEEP ALWAYS.

Aktivní panel v každém Firefox okně, pinned panel a hrající audio jsou podle nastavení chráněné.

Panely

Okna jsou ve výchozím stavu sbalená. Fulltext hledá současně v názvu panelu, URL a názvu skupiny; při hledání se odpovídající části automaticky rozbalí. Filtry Stav a Politika lze kombinovat.

Rozbalit vše a Sbalit vše ovládají strom panelů. Vždy rozbalené drží všechna okna a skupiny otevřené. Automatické obnovování každých 5, 10, 30 nebo 60 sekund zachovává ruční stav rozbalení.

DEEP ručně uvolní obsah panelu z paměti, ale jeho pozice, skupina a URL zůstanou zachované.

DEEP skupinu uvolní vhodné panely skupiny. DEEP ALL provede hromadné uvolnění s respektem k ochranám, KEEP a EXCEPT.

EXCEPT u panelu po potvrzení přidá nebo odebere výjimku KEEP pro přesnou aktuální URL.

Workspaces

Workspace je uložená sada více Firefox oken. Každé okno obsahuje své pořadí panelů a tab groups.

Uložit stav
Vynutí okamžité uložení aktuálního stavu aktivního workspace. V současném LIVE režimu se workspace průběžně aktualizuje i automaticky.
Uložit akt. stav jako nový
Vytvoří nový workspace přímo z aktuálně otevřených Firefox oken, skupin a panelů a po kontrole ho aktivuje.
Import JSON
Importuje jeden workspace. Pokud už stejné jméno existuje, vyžádá nový název nebo lze import zrušit.
Backup workspaces
Exportuje všechny uložené workspaces do jednoho verzovaného JSON souboru.
Restore workspaces
Importuje kolekci workspace z backupu. Existující workspaces nepřepisuje a konfliktní názvy se musí přejmenovat.
Přepnout / Obnovit
Uloží aktuální stav, obnoví cílový workspace a teprve po ověření jeho oken zavře okna současného workspace.
Přejmenovat
Změní jen uživatelský název workspace.
Smazat
Smaže uloženou definici. Při smazání aktivního workspace zůstanou aktuální okna otevřená a převezme je nový workspace.

Zavření jednoho okna přes X workspace nesmaže. Záměr native X Firefox API neumí sdělit, takže bezpečné výchozí chování je stav okna zachovat.

Nastavení, Backup a Sync

Politika hostname platí pro celý přesný hostname/subdoménu. URL výjimka má vyšší prioritu než hostname.

Záloha aplikace uloží všechny workspaces, nastavení AUTO, politiky hostname, URL výjimky, volbu Sync, známé hosty, statistiky a stabilní předvolby UI do jednoho verzovaného souboru JSON. Runtime ID se neexportují.

Obnova aplikace nahradí trvalý stav ze zálohy, ale nezavírá otevřená Firefox okna. Jednoznačná přesná shoda automaticky připojí existující okna; nejednoznačné nebo změněné relace se nepřipojí a Recover před možnými duplicitami vyžádá potvrzení.

Firefox Sync je volitelný. Synchronizuje AUTO nastavení, hostname politiky a URL výjimky. Runtime ID, countdowny, statistiky používání a snapshoty workspace zůstávají lokální.

Popup a statistiky

Popup je rychlý dashboard: aktivní workspace, počet oken, panelů a skupin, loaded/deep stav a počty AUTO, KEEP, DEEP ALWAYS a EXCEPT.

Statistika hostname sleduje aktivní a neaktivní čas. Slouží jako podklad pro budoucí návrhy, zda má být málo používaný hostname převeden z AUTO na DEEP ALWAYS.

Vývojová verze

Při spuštění přes web-ext se rozšíření při změně souborů automaticky znovu načte. Otevřený panel správce na moz-extension:// se může zavřít. Nainstalovaná verze tyto vývojové hlídače nepoužívá.
